# Harness logos

Icons used by the README to identify the harnesses this plugin migrates from.

- `pi.svg` — pi's pixel mark, adapted from `earendil-works/pi` (`apps/p2/public/icons/favicon.svg`).
- `opencode.svg` — opencode mark, adapted from the official `anomalyco/opencode` favicon / Simple Icons (CC0).
- `codex.svg` — OpenAI mark from Simple Icons (CC0), identifying OpenAI Codex.
- `claude-code.svg` — Claude mark from Simple Icons (CC0), identifying Claude Code.
- `workbuddy.png` — WorkBuddy application icon (Tencent), used only to identify the supported software.
- `dsh.png` — DeepSeek Harness application icon, used only to identify the target harness.
